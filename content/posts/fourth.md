### 正文
{{< admonition type=tip title="建议" open=true >}}
先点开图片浏览一遍，思考一下对页之间的关联性。

拿一张纸和一支笔，写下想法，穷尽自己的发散思维。

希望在评论区看到大家和我不同的想法！
{{< /admonition >}}

##### 1
{{< image src="/my_site/4/1.JPG" title="" caption="" >}}

红色。是一组对称的三角形，同时两个都是外面一个三角形，里面一个（鲨鱼头、嘴巴）。都是粗糙质感。画面整体都比较亮

##### 2
{{< image src="/my_site/4/2.JPG" title="" caption="" >}}

红、白、蓝色。天空占比都相当大。都有三角形（这一次还会注意到鲨鱼的牙齿）。整体较亮。

##### 3
{{< image src="/my_site/4/3.JPG" title="" caption="" >}}

颜色。三角形（锯齿）。旗子和锯齿片都是水平排布。右边很明显是浅景深。右边有明暗关系。右边的“桌面”上有水平纹理，对应左边的线。整体依旧较亮。

##### 4
{{< image src="/my_site/4/4.JPG" title="" caption="" >}}

整体色调较暖。楼梯侧面也是“锯齿”状。右边有曲线，更具动感。右边是明暗渐变，左边是明暗对比。
##### 5
{{< image src="/my_site/4/5.JPG" title="" caption="" >}}

曲线。右边有点像是从最顶部俯视这个楼梯，发现楼梯螺旋下降，同时是外围（近处）大，内部（远处）小，虽然我不确定这根“草”究竟是三维空间中卷曲还是二维平面的卷曲。有趣的是这根绿色的“草”在这暖色中跳了出来，很醒目。
##### 6
{{< image src="/my_site/4/6.JPG" title="" caption="" >}}

曲线不用多说。但关键是这两张的跨度太大了，从实物到一张地图，越看越妙！
##### 7
{{< image src="/my_site/4/7.JPG" title="" caption="" >}}

有很多的线。黑、红、黄色。都有密密麻麻的部分。都是二维。都是一种示意图。
##### 8
{{< image src="/my_site/4/8.JPG" title="" caption="" >}}

有很多相近的颜色。左右一亮一暗，对比明显。左边的颜色都被框在黑色中，右边的颜色都在黑暗外面。
##### 9
{{< image src="/my_site/4/9.JPG" title="" caption="" >}}

颜色。直线。明暗对比。从相对“光怪陆离”变为“四平八稳”、“充满希望”。
##### 10
{{< image src="/my_site/4/10.JPG" title="" caption="" >}}

海边，钓鱼。有点时间顺序的感觉。右边的天际线实际上看不到，但是通过左边的图片，仿佛可以看出来。
##### 11
{{< image src="/my_site/4/11.JPG" title="" caption="" >}}

因果关系。左边空旷，右边密集
##### 12
{{< image src="/my_site/4/12.JPG" title="" caption="" >}}

这个跨度也超大，从卖鱼到卖书。都是密密麻麻的。整体影调相似。
##### 13
{{< image src="/my_site/4/13.JPG" title="" caption="" >}}

书的侧面也是长方形。右边显然很粗糙。
##### 14
{{< image src="/my_site/4/14.JPG" title="" caption="" >}}

虽然都是形状的堆叠，但是右边夸了一个大步，颜色不同，以及每一块玻璃好像透明度也不一样。红色依旧是锚点。
##### 15
{{< image src="/my_site/4/15.JPG" title="" caption="" >}}

颜色。影调转变。景深改变。
##### 16
{{< image src="/my_site/4/16.JPG" title="" caption="" >}}

人工盆栽。植物。颜色。
##### 17
{{< image src="/my_site/4/17.JPG" title="" caption="" >}}

植物。颜色。从人工的、小的植物，变成自然的、大的植物。右边的太阳照下来，照在左边的盆栽上出现影子。左边的植物长大后会不会是右边的植物？
##### 18
{{< image src="/my_site/4/18.JPG" title="" caption="" >}}

向四周伸出去的树干和触角。
##### 19
{{< image src="/my_site/4/19.JPG" title="" caption="" >}}

向四周伸出。主体色调相似。左边的圆脑袋到了右边的四周（也挺符合章鱼的）。从直立变成了斜着。
##### 20
{{< image src="/my_site/4/20.JPG" title="" caption="" >}}

颜色。形状。右边浅景深。两边主体的质感相似。
##### 21
{{< image src="/my_site/4/21.JPG" title="" caption="" >}}

这个挺有意思的，就像橙子掉下来在地上砸了个坑。
##### 22
{{< image src="/my_site/4/22.JPG" title="" caption="" >}}

形状。颜色。两边都比较“接地气”，裸露的沙土地和石头房子会很大概率出现在同一地点。
##### 23
{{< image src="/my_site/4/23.JPG" title="" caption="" >}}

形状，右边将房子拆成两部分了。
##### 24
{{< image src="/my_site/4/24.JPG" title="" caption="" >}}

我的想法是，这两个骰子不仅是从左边的骰盅中摇出来的，也是从右边两条滑滑梯上滑下来的。右边给人一种稍微破败的感觉，这时反观左边也会发现骰盅有点像是古董。
##### 25
{{< image src="/my_site/4/25.JPG" title="" caption="" >}}

说实话，这个我从画面形式上真的没看出任何关联。唯一能解释的就是去识别图中的文字，从而知道——在我写这句话时，我突然发现这里的牌子也是两个，正好对应两条滑滑梯——是在说这个小游乐场是在开放的。
##### 26
{{< image src="/my_site/4/26.JPG" title="" caption="" >}}

其实当我写这篇文章时已经是我第三甚至是第四次看这本书了，前面几次我对这两张的理解都是在识别图片中的文字基础上。但我这次突然发现，右边柱子上的横向条纹是对应左侧窗帘上的横向条纹，包括右边的横向的房梁。
##### 27
{{< image src="/my_site/4/27.JPG" title="" caption="" >}}

左边是红白相间条纹，右边是蓝白相间条纹。箭头。红蓝对比色。直立的柱子。还有一个有意思的点是：左边的箭头指向一致，方向明确，从而整张图像都是清晰、明亮的；右边的箭头向各个方向的都有，使人混乱，而图像中的大雾天气正好衬托了这种摸不着方向的基调。而且左右图片的右后方也都有相似的竖立的物体。
##### 28
{{< image src="/my_site/4/28.JPG" title="" caption="" >}}

颜色。柱子。天气对比。情绪对比。
##### 29
{{< image src="/my_site/4/29.JPG" title="" caption="" >}}

在刚刚的对页中看着面旗子并没有很强烈的风的感觉，但是这一张对页就很绝，强风的感觉一下就出来了。色调对比。冷静的蓝色到热情的暖色，甚至是一种“危险的预警”感觉。
##### 30
{{< image src="/my_site/4/30.JPG" title="" caption="" >}}

暖色。朝向一致。从二维到三维。
##### 31
{{< image src="/my_site/4/31.JPG" title="" caption="" >}}

颜色。数量。从三维主体变成二维主体，从二维背景变成三维背景。从“温顺”变得“凶狠”。很像左边在看右边的打架。
##### 32
{{< image src="/my_site/4/32.JPG" title="" caption="" >}}

左边的狮王争斗发生在怪异恐怖的树下。主体都是二维，都是黑色。
##### 33
{{< image src="/my_site/4/33.JPG" title="" caption="" >}}

##### 34
{{< image src="/my_site/4/34.JPG" title="" caption="" >}}
